# 🛡️ มาตรการความปลอดภัยของระบบ (Frontend Web Security Baseline)

เอกสารนี้ระบุแนวทางและมาตรการด้านความปลอดภัย (Security Best Practices) สำหรับโปรเจกต์ **Speaker Showcase Website (North Assembly)** ภายใต้สถาปัตยกรรม **React 19 + TypeScript + Vite**

---

## 1. การป้องกันการโจมตีฝั่งไคลเอนต์ (XSS — Cross-Site Scripting Prevention)

การโจมตีแบบ XSS มักเกิดขึ้นเมื่อแอปพลิเคชันนำข้อมูลที่ไม่น่าเชื่อถือมารันเป็นโค้ด JavaScript บนเบราว์เซอร์ของผู้ใช้

### มาตรการบังคับใช้:
1. **พึ่งพาการ Escape อัตโนมัติของ React JSX:**
   - React มีกลไกเข้ารหัสอักขระพิเศษ (Auto-escaping) โดยอัตโนมัติเมื่อเรนเดอร์ข้อความผ่าน `{expression}` ป้องกันการฉีดมาร์กอัป HTML ที่เป็นอันตราย
2. **ห้ามใช้ `dangerouslySetInnerHTML` โดยเด็ดขาด:**
   - ห้ามนำ `dangerouslySetInnerHTML` มาใช้ในการแสดงผลชีวประวัติหรือชื่อของวิทยากร ข้อมูลทั้งหมดต้องเรนเดอร์ผ่าน JSX ปกติ
3. **การตรวจสอบและคัดกรองลิงก์ (URL Sanitization):**
   - ทุกลิงก์ที่สร้างขึ้นต้องใช้โพรโทคอลที่ปลอดภัย (`https://` หรือ Internal Path เช่น `/e-report`)
   - ห้ามรับ URL ที่ขึ้นต้นด้วย `javascript:...` หรือ `data:text/html,...` เข้ามาแสดงในแท็ก `<a>` หรือ `<img>`
4. **ความปลอดภัยของ External Links:**
   - เมื่อมีลิงก์เปิดหน้าต่างใหม่ (`target="_blank"`) ต้องแนบ `rel="noopener noreferrer"` เสมอ เพื่อป้องกันปัญหา Reverse Tabnabbing

---

## 2. ความปลอดภัยของรูปภาพและ External Assets

- **การโหลดรูปภาพผ่าน HTTPS:**
  - รูปภาพวิทยากรและแกลเลอรีทั้งหมดถูกโหลดจาก CDN ที่น่าเชื่อถือ (เช่น Unsplash) ผ่านโพรโทคอล `https://`
- **การกำหนด `alt` Text สำหรับความปลอดภัยและ a11y:**
  - รูปภาพทุกรูปต้องมีคำอธิบาย `alt` ที่เหมาะสม หรือระบุ `aria-hidden="true"` สำหรับรูปภาพที่เป็นเพียงองค์ประกอบตกแต่ง เพื่อป้องกันข้อผิดพลาดในการตีความของ Screen Reader

---

## 3. ความปลอดภัยของโค้ดบันเดิลและความลับระบบ (Bundle Hygiene & Secret Protection)

- **ห้ามใส่ API Keys หรือความลับใน Frontend Code:**
  - โค้ดในโฟลเดอร์ `src/` จะถูกคอมไพล์และเปิดเผยสู่สาธารณะบนเบราว์เซอร์ของผู้ใช้ จึง **ห้ามฝัง Token, Private Keys, หรือ Credentials ใดๆ ไว้ในโค้ดฝั่งหน้าบ้านเด็ดขาด**
- **การตั้งค่า `.antigravityignore` และ `.gitignore`:**
  - กำหนดให้ระบบละเว้นไฟล์คอนฟิกชั่วคราว ไฟล์ล็อก และโฟลเดอร์ `dist/`, `node_modules/` เพื่อป้องกันการเผลอส่งไฟล์ข้อมูลระบบขึ้น Version Control

---

## 4. มาตรการความปลอดภัยของ Dependency (Dependency Security)

- ตรวจสอบช่องโหว่ของ Third-party Packages ผ่านคำสั่งตรวจสอบมาตรฐาน:
  ```bash
  npm audit
  ```
- ในปัจจุบัน โปรเจกต์มีช่องโหว่ความปลอดภัยเป็น **0 vulnerabilities** (ผ่านการตรวจสอบโดย npm audit)
